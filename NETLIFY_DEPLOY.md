# 🚀 Déploiement ComptaFlow sur Netlify

Votre projet est prêt ! J'ai généré le dossier `dist` qui contient tout le code optimisé.

### 📁 Ce qu'il faut déposer :
Vous devez faire glisser le dossier suivant sur Netlify :
`C:\Users\user\flowcompta\dist`

### 🛠️ Étapes à suivre :

1.  Ouvrez **[Netlify Drop](https://app.netlify.com/drop)** (ou connectez-vous à votre compte).
2.  Prenez le dossier **`dist`** qui se trouve dans `C:\Users\user\flowcompta\` et faites-le glisser dans la zone grise de la page Netlify.
3.  Une fois le téléchargement fini, Netlify va vous donner une URL temporaire.
4.  **Pour changer le nom en "ComptaFlow" :**
    *   Allez dans **Site settings** (Paramètres du site).
    *   Cliquez sur **Change site name** (Changer le nom du site).
    *   Tapez `comptaflow`. 
    *   Si disponible, votre adresse sera : `https://comptaflow.netlify.app`.

### ⚡ Rappel important :
J'ai ajouté un fichier caché nommé `_redirects` pour que la navigation de votre application fonctionne parfaitement sur Netlify.
