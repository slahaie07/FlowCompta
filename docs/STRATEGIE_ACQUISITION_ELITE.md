# 🎯 STRATÉGIE D'ACQUISITION ÉLITE (ZÉRO SPAM)
> **Directives de croissance pour ComptaFlow**

## ⚠️ AVERTISSEMENT DE SÉCURITÉ ET DE RÉPUTATION
Le "flooding" (envoi massif d'emails non sollicités) est **strictement proscrit**.
1. **Légal** : Il viole la Loi canadienne anti-pourriel (LCAP) et le RGPD.
2. **Technique** : L'envoi massif d'emails froids via Resend/Google détruira la réputation de votre nom de domaine en moins de 24 heures (Blacklistage par Gmail/Outlook). Vos emails légitimes (factures, mots de passe) n'arriveront plus.
3. **Image de Marque** : Une marque "Premium Elite" ne spamme pas. Elle attire et sélectionne ses clients.

## 🚀 LA SOLUTION : LE SYSTÈME "OUTBOUND" HAUTE PRÉCISION

Au lieu de flooder, nous utilisons les skills `marketing-automation` et `sales-automator` pour exécuter une approche "Sniper".

### Phase 1 : Chasse Chirurgicale (Elite Hunter)
L'automatisation `n8n-elite-hunter.json` déjà en place permet de :
1. **Cibler** : Scraper uniquement les profils LinkedIn correspondant parfaitement à votre cible (ex: "CEO", "Fondateur", "Québec", "Fintech").
2. **Qualifier** : Le système ne sélectionne que les entreprises ayant plus de 2 ans d'existence (celles qui ont un vrai besoin de CFO).

### Phase 2 : Cold Emailing Personnalisé (Max 50/jour)
L'IA (Gemini 2.5) génère un message *unique* pour chaque prospect.
*   **Approche** : "Bonjour [Nom], j'ai analysé la croissance de [Nom de l'entreprise]. En tant qu'Architecte Financier, j'ai remarqué que..."
*   **Volume** : Envoi de petits volumes très ciblés. Taux d'ouverture attendu : > 60%. Taux de réponse : > 15%.

### Phase 3 : Inbound Marketing (L'Aimant à Clients)
Attirez les clients vers vous avec des outils gratuits hébergés sur `agy-platform.vercel.app` :
1. **L'Outil Gratuit** : Mettez en ligne un "Calculateur de Runway SaaS" ou un "Test de Santé Fiscale". Pour voir les résultats, l'utilisateur doit laisser son email.
2. **Retargeting** : Utilisez la balise Meta Pixel ou Google Tag Manager pour recibler les visiteurs de votre site avec des publicités haut de gamme.

### Phase 4 : Close Automatisé (Sales Automator)
Dès qu'un prospect montre de l'intérêt, le système `sales-automator` prend le relais :
1. Prise de rendez-vous automatisée via Google Calendar.
2. Envoi automatique du contrat de mandat généré par `contractEngine.ts`.
3. Paiement via Stripe Checkout (Déjà configuré).

**CONCLUSION** : Ne visez pas la quantité. Visez 100 clients de très haute qualité qui paieront 500$/mois. C'est ainsi que l'on construit un empire d'un demi-million de dollars récurrents.
