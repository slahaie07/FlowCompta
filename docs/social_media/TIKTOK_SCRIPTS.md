## Slideshow animé (sans montage)

1. Ouvrir `public/marketing/tiktok/slideshow-promo.html` dans **Chrome**
2. **F11** plein écran
3. Enregistrer avec **Win+G** (Xbox Game Bar) ou **OBS** en 1080×1920
4. Boucle 25 s — exporter en MP4
5. Importer dans **CapCut** → ajouter voix off + musique → publier TikTok

## CapCut (alternative rapide)

1. Importer les 4 PNG du dossier `public/marketing/tiktok/`
2. Durée 4–5 s par slide + transition « Glitch » ou « Fade »
3. Texte auto-généré depuis ce document
4. Export 1080p 30fps → TikTok
